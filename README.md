# Tröpfli

Kapazitiver Pflanzen-Feuchtesensor mit lokalem Gateway und PWA. Strikt lokal, keine Cloud.

| Ordner | Inhalt |
|---|---|
| `docs/` | Anforderungen, Konzepte, Datenblätter (+ `INDEX.csv`), App Notes, Referenzen, Prüfberichte, Anleitungen |
| `hardware/` | KiCad-Projekte Sensor und Gateway |
| `mechanical/` | FreeCAD, STEP, STL/3MF |
| `simulation/` | SPICE, Feld- und FEM-Simulationen |
| `firmware/` | Sensor- und Gateway-Firmware |
| `app/` | PWA |
| `renders/` | Blender-Skripte und Renderings |
| `scripts/` | Generatoren, Berechnungen, `toolcheck.sh` |
| `production/` | Release-Pakete pro Revision |

Projektregeln für Mensch und Agenten: [CLAUDE.md](CLAUDE.md). Rollen: [.claude/agents/](.claude/agents/).
Status: **Phase 0** (Toolcheck und Restfragen).
